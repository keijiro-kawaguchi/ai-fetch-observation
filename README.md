# AI fetcher observation pages

Research pages by **Nihonbashi AI Lab**. We measure what AI fetchers (for example ChatGPT-User and Claude-User) and search or training crawlers receive from a page, and whether they find a freshly published page on their own. No personal data is collected: for bot-like visits only, the user agent, source IP and headers are recorded; for browser visits, only a count.

## 日本語

日本橋 AI Lab の研究用のページです。AI の取得者（ChatGPT-User・Claude-User など）や、検索・学習用のクローラーが、ページから何を受け取るか、新しく置かれたページに自然に来るかを調べています。個人の情報は集めません。取得者らしい来訪についてだけ、UA・接続元 IP・ヘッダーを記録し、ブラウザからの来訪は件数だけを数えます。
